# Student Portfolio Project Tracker

## Objective

The objective of this project is to help students plan, track, and document practical academic software projects that can be showcased on GitHub as part of portfolio-driven development.

## Description

Student Portfolio Project Tracker is a responsive browser-based application that stores project details in the browser using `localStorage`. A student can add project titles, objectives, technologies, deadlines, progress values, and status labels. The dashboard summarizes total projects, active projects, average progress, and the nearest deadline.

## Tools and Technologies

| Technology | Purpose |
| --- | --- |
| HTML5 | Builds the structure of the application |
| CSS3 | Provides responsive layout and visual styling |
| JavaScript | Handles data storage, rendering, filtering, deletion, and export |
| Browser localStorage | Stores project records without a backend server |
| Git and GitHub | Version control and portfolio publishing |

## Features

- Add portfolio project details with deadline, objective, technology, progress, and status.
- View dashboard metrics for total projects, active projects, average progress, and nearest deadline.
- Filter projects by status.
- Delete completed or incorrect project records.
- Export a text summary of all projects.
- Works offline in any modern browser.

## Execution Steps

1. Download or clone the repository.
2. Open `index.html` in a modern browser.
3. Add or update project records using the form.
4. Use the status filter to inspect project progress.
5. Click **Export Summary** to download a text summary.

## Output

The application displays a dashboard and a list of project cards. Each card shows the project objective, technology, deadline, current status, and progress bar.
